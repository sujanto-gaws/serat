# UI design artifacts (owner: frontend-designer)

- tokens.css — the same tokens as `--serat-*` CSS custom properties, installed into app/src/styles/
- live-preview.css — reference stylesheet for editor typography (screens/editor.md, Live-preview typography)
- components.md — component inventory with variants/states
- screens/<screen>.md — per-screen spec: layout, states, responsive rules, a11y notes, REQ IDs served
